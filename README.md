# NCHU-CS-OS

Operating Systems — National Chung Hsing University

## Teaching Assistant

大家好，我是本學期「作業系統（Operating Systems）」課程的助教。

本 Repository 主要用於整理與提供課程相關資源，包含作業（Homework）、實驗（Lab）、範例程式以及其他補充資料。

本學期我會協助各位進行作業與實驗，並協助處理程式實作、Linux 系統操作及作業系統相關問題。

若在課程、作業或實驗過程中遇到問題，歡迎提出並一起討論。希望大家能透過實際操作與程式實作，更深入理解作業系統的核心概念。

祝大家本學期學習順利！
